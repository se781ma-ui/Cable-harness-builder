# Cable Harness Builder (Demo)

Python web application for automated cable harness design and specification generation.

## The Problem

Designing a cable harness manually takes a full working day:
- Calculating cable lengths and routing
- Selecting components (connectors, terminals, wires)
- Building the specification

## The Solution

This tool automates the process:
- Add connectors
- Route connections between them
- Select components from built-in library
- Get calculation result in seconds

**No more manual table work — the machine does it.**

## Features

- Add connectors
- Route connections between them
- Select components from built-in library
- Automatic calculation of harness parameters
- Specification generation
- Demo version included

## Tech Stack

- Python 3.11+
- HTML, CSS

## How It Works

1. Add connectors to the harness
2. Route connections between them
3. Select components from library
4. Get instant calculation and specification
